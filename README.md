# ryszard-twardy.github.io

Static portfolio landing page for the GitHub Pages user site. Plain HTML and CSS, no build step, no framework, no CDN: fonts and icons are self-hosted under `assets/`.

Preview locally: run `python -m http.server 8000` in the repo root and open http://localhost:8000.
