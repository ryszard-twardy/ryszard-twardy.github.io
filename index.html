About

I build customer and sales analytics that end in a decision: in the case below, where a win-back budget should go. I do the whole chain myself, from the SQL that cleans the data to the Power BI model to the page a manager reads, and I write the design decisions down so the next person can check them.

Nineteen years of geospatial analysis and data management came before that, seventeen of them at a national park in Poland where I ended up running the GIS. What carried over: standardise the sources, document the method, report only what can be traced.

Selected work

Kupferkanne: fifteen thousand customers, one retention budget

A direct-to-consumer coffee-equipment brand selling in nine European markets has one win-back budget and no evidence on which customers it should go to.

  • RFM segmentation across 168,777 orders, built from roughly 460K raw records
  • Nine-step SQL pipeline, 109 DAX measures, what-if reactivation model
  • Architecture decisions on the record

Fictional brand, synthetic data generated with synth-datagen (below). The engineering is real.

BigQuery, Power BI (PBIP/TMDL), DAX, Python, Quarto

synth-datagen: dirty data, on purpose

Portfolio analytics built on clean sample data never meet the defects a real cleaning layer has to survive, and public datasets cannot be regenerated when the model changes.

  • Five business scenarios, multi-table, byte-identical from a seed
  • Duplicate orders, cents-format inconsistency, orphan keys, type drift
  • Feeds the Kupferkanne pipeline: 80 CSV shards, roughly 460K records
$ synth-datagen retail --seed 42 --output ./out/retail \
    --rows fact_orders=500,fact_order_items=1500,fact_payments=500 \
    --export-parquet --data-quality medium

How I work

Business problem first. Every report starts from a decision someone has to make, not from a dataset. Titles state the finding; the recommendation carries a number and a cost.

Built to be checked. Star schema in the warehouse, semantic model under version control as PBIP/TMDL, SQL linted, design decisions logged. The code matches the claim.

AI tools, my judgement. I use AI-assisted tooling for code and drafts. The design, the tests and the responsibility for what ships are mine, and both repositories are public so that can be checked.
